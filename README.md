# portfolio

Personal portfolio site built with React and Vite, deployed on Vercel.

Live at [harrysavill.dev](https://www.harrysavill.dev)

---

## stack

- React
- Vite
- Vanilla CSS
- Vercel

---

## features

- Dark / light mode toggle
- Smooth scroll navigation
- Responsive layout with mobile hamburger menu
- Sections: about, skills, projects, contact

---

## getting started

### prerequisites

- Node.js

### install and run

```bash
git clone https://github.com/harrysavill/portfolio.git
cd portfolio
npm install
npm run dev
```
